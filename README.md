A 100-word monologue for a fantasy villain who is secretly just very tired. He has stood at the same walls for nine years, buried three armies, and collects the dreams of kings in jars he can no longer quite find. The tiredness lives in the pauses, the forgotten name and the small deflections; he never announces it, and he is still dangerous. `main.py` writes the monologue to `/output/entry.txt` and checks it against the bounty gate (1–600 characters, about 100 words) before writing.

## Run it

```sh
python3 main.py
```
